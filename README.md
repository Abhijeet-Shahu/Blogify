# Blogify
A Blog Website which shows all the Blogs free for all

## Environment variables

- `SUPABASE_DATABASE_URL`: Supabase PostgreSQL JDBC URL, for example `jdbc:postgresql://HOST:5432/postgres?user=USER&password=PASSWORD&sslmode=require`
- `GROQ_API_KEY`: Groq API key used for blog content generation
- `GROQ_MODEL`: optional Groq model override, defaults to `llama-3.3-70b-versatile`
- `STABILITY_API_KEY`: existing Stability key used for image generation
